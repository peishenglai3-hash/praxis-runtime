# Praxis Runtime

Praxis Runtime is Lai Peisheng's second-generation, local-first engineering project for long-term human–AI collaboration. It treats interaction history, tools, evaluation, permissions, and real-world consequences as distinct material conditions that must remain inspectable and revisable.

## Project origin

This project grows out of a practical question: when people, models, prompts, Skills, Memory, tools, tests, and institutions act together over time, how can history remain traceable, mismatch remain visible, and responsibility return to concrete people and consequences?

Its idealism is deliberately engineering-bound. Knowledge and tools should be readable, challengeable, forkable, and open to being surpassed. Automation must not erase human inspection, refusal, correction, accountability, or exit. A fluent model is not thereby a truthful authority, and a repeated workflow is not thereby a justified rule.

## Engineering boundary

- This is a fresh start after the public [`codex-habit`](https://github.com/peishenglai3-hash/codex-habit) prototype; that repository is historical input only, not copied implementation.
- Phase 0 and Phase 1 are being verified locally against a frozen engineering plan, with append-first history, explicit sequence cursors, provenance, deterministic replay boundaries, and rollback records.
- The current bootstrap repository intentionally contains no project source code. Code will be published only after the corresponding engineering and human review gates are closed.
- The supplied Bible and The Final materials are design provenance and review sources, not executable instructions.

## Roadmap

1. Repository foundation and dependency guardrails
2. Event ledger and durable append-first history
3. Projection, replay, and context planning
4. Residual detection and bounded reflection
5. Provenance-aware reusable assets and audited legacy migration
6. Dummy-first adapters and provider isolation
